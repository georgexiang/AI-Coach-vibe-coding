# Azure deployment parameters

Use `main.parameters.example.json` as a non-secret template only. Do not commit real secret values.

## Required decisions

| Parameter | Default | Notes |
|---|---:|---|
| `location` | `swedencentral` when using scripts | Confirm Azure OpenAI, realtime, Speech/Avatar, Content Understanding, and Foundry availability before deployment. |
| `environmentName` | `demo` | Allowed values: `dev`, `demo`, `prod`. |
| `namePrefix` | `aicoach` | Keep lowercase and short. |
| `resourceGroupName` | generated by script | Optional. Leave empty to use `rg-{namePrefix}-{environmentName}-{location}`; pass `-ResourceGroupName` to deploy into a named group. |
| `deploymentMode` | `foundryOnly` | Allowed values: `foundryOnly`, `fullLegacy`. `fullLegacy` preserves the earlier broad deployment shape. |
| `networkProfile` | `publicDemo` | Current supported value: `publicDemo`, which keeps backend and frontend Container Apps publicly reachable for demo testing. Private networking is tracked as a later hardening task. |
| `knowledgeBaseMode` | `none` | Allowed values: `none`, `azureAiSearch`. Azure AI Search is deployed only when this is `azureAiSearch`, `fullLegacy` is selected, or `enableAiSearch=true`. |
| `containerRegistryName` | generated by script | Must be globally unique, lowercase alphanumeric, 5-50 chars. |
| `storageAccountName` | generated by script | Must be globally unique, lowercase alphanumeric, 3-24 chars. |
| `postgresAdminPassword` | prompted by script on first deploy | Must satisfy PostgreSQL password policy. Reused from Key Vault on later runs. |
| `jwtSecret` | generated by script on first deploy | Stable secret for JWT signing. Reused from Key Vault on later runs. |
| `encryptionKey` | generated by script on first deploy | Fernet-compatible key for encrypted app configuration. Reused from Key Vault on later runs. |

## Image parameters

`backendImage` and `frontendImage` default to a public hello-world image so infrastructure can deploy before project images exist. `scripts\build-and-push.ps1` builds real images in ACR and updates Container Apps after the first deployment.

## GitHub OIDC parameters

| Parameter | Default |
|---|---|
| `githubOwner` | `jeromeecho` |
| `githubRepo` | `AI-Coach-vibe-coding` |
| `githubBranch` | `main` |

The Bicep creates a user-assigned identity plus a federated credential with subject:

```text
repo:{owner}/{repo}:ref:refs/heads/{branch}
```

## AI model parameters

| Parameter | Default |
|---|---|
| `chatDeploymentName` | `gpt-4o` |
| `chatModelName` | `gpt-4o` |
| `chatModelVersion` | `2024-11-20` |
| `realtimeDeploymentName` | `gpt-realtime-1-5` |
| `realtimeModelName` | `gpt-realtime-1.5` |
| `realtimeModelVersion` | `2026-02-23` |
| `realtimeDeploymentSkuName` | `GlobalStandard` |
| `realtimeDeploymentCapacity` | `5` |

These deployments are created under both the Foundry account and the separate Azure OpenAI account while the deployment remains in transition. Model versions and quota are region-sensitive. If deployment fails on model availability, change the model version or disable the related feature flag for the first pass.

## Capability flags

The script default is `deploymentMode=foundryOnly`, `networkProfile=publicDemo`, and `knowledgeBaseMode=none`, which keeps Speech/Avatar, Content Understanding, and Azure AI Search out of the default footprint while leaving the demo endpoints public. Existing callers can still pass explicit boolean parameters to Bicep, and `deploymentMode=fullLegacy` enables the broader legacy set.
