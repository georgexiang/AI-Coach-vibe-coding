# Plan 01: State Machine (draft -> active -> archived)

**Phase:** 22 — Scenarios 模块二次重构
**Decision:** D-04
**Depends on:** None

## Goal

Extend the Scenario status field from two states (draft/active) to three states (draft -> active -> archived) with validated transitions, read-only enforcement on archived scenarios, archive confirmation UX, and archived filter support on the list page.

- [ ] Backend enforces linear state transitions: draft->active, active->archived (no other transitions allowed)
- [ ] Archived scenarios return 400 on update attempts

- [ ] Clone from archived scenario creates a new draft copy
- [ ] Archive action requires confirmation dialog
- [ ] All existing backend tests still pass

- [ ] E2E test validates the archive flow end-to-end

```python
async def transition_status(
    db: AsyncSession, scenario_id: str, new_status: str
) -> Scenario:
    """Transition scenario status with validation."""
    scenario = await get_scenario(db, scenario_id)
    allowed = VALID_TRANSITIONS.get(scenario.status, set())
    if new_status not in allowed:
        bad_request(
            f"Cannot transition from '{scenario.status}' to '{new_status}'. "
            f"Allowed transitions: {allowed or 'none'}"
        )
    scenario.status = new_status
    await db.flush()
    await db.refresh(scenario)
    return scenario
```

    """Tests for state machine transitions."""

    async def test_draft_to_active(self, db_session):
        # Create scenario in draft status, transition to active
        ...
        result = await transition_status(db_session, scenario.id, "active")
        assert result.status == "active"

    async def test_active_to_archived(self, db_session):
        # Create active scenario, transition to archived
        ...
        result = await transition_status(db_session, scenario.id, "archived")
        assert result.status == "archived"

    async def test_invalid_transition_draft_to_archived(self, db_session):
        # Cannot skip active
        with pytest.raises(BadRequestException):
            await transition_status(db_session, scenario.id, "archived")

    async def test_invalid_transition_archived_to_active(self, db_session):
        # Archived is terminal
        with pytest.raises(BadRequestException):
            await transition_status(db_session, scenario.id, "active")

    async def test_update_archived_scenario_raises(self, db_session):
        # Archived scenario rejects updates
        with pytest.raises(BadRequestException):
            await update_scenario(db_session, scenario.id, ScenarioUpdate(name="New"))

    async def test_clone_archived_scenario_succeeds(self, db_session):
        # Clone from archived creates draft
        clone = await clone_scenario(db_session, scenario.id, user_id)
        assert clone.status == "draft"
