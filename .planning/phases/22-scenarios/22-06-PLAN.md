# Plan 06: I18N Global Audit

**Phase:** 22 — Scenarios 模块二次重构
**Decision:** D-02
**Depends on:** Plan 05 (editor must be complete — audit covers the new editor component)

## Goal

Comprehensive audit of ALL frontend pages and components to eliminate every hardcoded text string. Ensure `en-US` and `zh-CN` locale JSON files are complete and in sync. Every user-visible string must go through `t()` from `useTranslation`. After this plan, no hardcoded English or Chinese text remains in any `.tsx` file.

- [ ] Zero hardcoded user-visible text in any frontend component/page
- [ ] `en-US` and `zh-CN` locale files have identical key sets (no missing keys)
- [ ] All `defaultValue` props removed from `t()` calls (keys must exist in locale files)
- [ ] Column headers, button labels, form labels, placeholder text, error messages all use `t()`
- [ ] Scenario table column headers internationalized (Name, Tags, HCP, Mode, Difficulty, Status, Actions)

- [ ] All status/badge text uses translation (draft, active, archived, easy, medium, hard, f2f, conference)
- [ ] Reports page product filters use system_enums labels (not hardcoded strings)

- [ ] E2E i18n switching test passes

1. Create a verification script `frontend/scripts/check-i18n.ts`:

```typescript
/**
 * i18n completeness checker.
 * Compares en-US and zh-CN locale files to ensure identical key sets.
 * Run: npx ts-node scripts/check-i18n.ts
 */
import * as fs from "fs";
import * as path from "path";

const localeDir = path.join(__dirname, "../public/locales");
const namespaces = ["admin", "common", "training", "scoring", "coach", "nav", "dashboard", "analytics", "conference", "skill", "voice", "meta-skill"];

let hasErrors = false;

for (const ns of namespaces) {
  const enPath = path.join(localeDir, "en-US", `${ns}.json`);
  const zhPath = path.join(localeDir, "zh-CN", `${ns}.json`);

  if (!fs.existsSync(enPath) || !fs.existsSync(zhPath)) continue;

  const enKeys = getAllKeys(JSON.parse(fs.readFileSync(enPath, "utf-8")));
  const zhKeys = getAllKeys(JSON.parse(fs.readFileSync(zhPath, "utf-8")));

  const missingInZh = enKeys.filter((k) => !zhKeys.includes(k));
  const missingInEn = zhKeys.filter((k) => !enKeys.includes(k));

  if (missingInZh.length > 0) {
    console.error(`[${ns}] Missing in zh-CN: ${missingInZh.join(", ")}`);
    hasErrors = true;
  }
  if (missingInEn.length > 0) {
    console.error(`[${ns}] Missing in en-US: ${missingInEn.join(", ")}`);
    hasErrors = true;
  }
}

if (hasErrors) {
  process.exit(1);
} else {
  console.log("All locale files are in sync!");
}

function getAllKeys(obj: Record<string, unknown>, prefix = ""): string[] {
  return Object.entries(obj).flatMap(([key, value]) => {
    const fullKey = prefix ? `${prefix}.${key}` : key;
    if (typeof value === "object" && value !== null) {
      return getAllKeys(value as Record<string, unknown>, fullKey);
    }
    return [fullKey];
  });
}
```

## Threat Model

| Threat | Mitigation |
|--------|-----------|
| Missing translation key shows raw key to user | check-i18n.ts script catches mismatches at build time; can add to CI |
| XSS via translation values | i18next escapes HTML by default; no `dangerouslySetInnerHTML` used |
| Locale file becomes invalid JSON (trailing comma, etc.) | JSON.parse in check script will throw on invalid JSON |

## Rollback

- Revert locale JSON files to previous state
- Revert component changes to use hardcoded text
- No database or backend changes in this plan
