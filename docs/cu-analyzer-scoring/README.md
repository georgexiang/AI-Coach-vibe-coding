# CU vs LLM 评分策略分析

> 本目录分析 AI Coach 平台中哪些评分维度适合使用 Azure Content Understanding (CU)，
> 哪些应该使用 LLM 直接评分，以及混合方案的推荐架构。
>

## 核心结论

| 维度类型 | 推荐引擎 | 原因 |
|----------|----------|------|
| 语音质量 (fluency/tone/pace/pronunciation) | **CU** ✅ | CU 原生音频分析能力，无需上下文 |
| 内容评分 (key_message/product_knowledge/...) | **LLM** ✅ | 需要 scenario 上下文、角色区分、目标导向评估 |
| 内容相关性预检 | **代码逻辑** ✅ | 简单关键词/规则检查，无需 AI |
